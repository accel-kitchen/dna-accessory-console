DNA Accessory · Console

コドンを選んで、DNAを光らせる。

DNAの4つの塩基（A・T・G・C）が3つ並んだものが「コドン」で、ひとつのアミノ酸を指定します。コドンを選ぶと、基板のLEDと3Dの二重らせんが同じ色で光り、そのアミノ酸の性質もわかります。

  1. 1コドンを選ぶ
  2. 21文字だけ変えてみる
  3. 3USBで基板へ送る

黄が鎖A、水色が鎖B。ドラッグで回転、ホイールで拡大、ダブルクリックで元の位置に戻ります。塩基対をクリックすると、基板の同じ位置のLEDが選ばれます。

コドン枠 codons

基板の4か所（3塩基対 = 6個ずつ）に表示するコドン。枠を選ぶと、下にそのコドンの中身が出ます。

アルファベット表 alphabet

アルファベット1文字は、アミノ酸1つを表します（M = メチオニン、など）。文字を選ぶと、そのアミノ酸のコドンが選んでいる枠に入り、紹介が出ます。

選んだコドン inspector

コドン表 genetic code

64通りのコドンと、指定されるアミノ酸の一覧。クリックすると、選んでいる枠のコドンが変わります。内側から1番目・2番目・3番目の塩基、外側がアミノ酸です。

桃色の枠が「同じアミノ酸になる仲間」、黒い枠が4つの枠のコドンです。

4つの塩基 bases

DNAの文字は A・T・G・C の4種類。大きさの違う2つのグループがあり、決まった相手とだけ水素結合でつながります。

文字をコドンに text → codon

入力した文字を、1文字につき1つのコドンに置きかえます。4文字ごとに1フレームになり、切り替えて表示されます。

「アミノ酸1文字」は M→ATG のように、アルファベット1文字が表すアミノ酸のコドンを使います（B・J・O・U・X・Z は対応なし）。「6bit ASCII」は、空白から「_」までの64文字を、塩基3つ（2ビット×3）に1対1で割り当てます。

翻訳してみる translation

4つの枠を5′から順に読み、アミノ酸をつなげていきます。読んでいるコドンは基板と3Dモデルでも光ります。終止コドンで止まります。

ペイント paint

基板のLEDをクリックして、1個ずつ・1塩基対ずつ・コドンごとに色を塗れます。
