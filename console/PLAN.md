# DNAアクセサリー制御コンソール 計画

作成日: 2026-10-29

## ゴール

- コドン・塩基・文字を指定して、基板上の好きな場所のLEDを光らせる。
- 文字を入力すると、その文字に対応するコドンを表示し、そのままLEDに反映する。
- ブラウザからマイコン（XIAO nRF52840）へ表示内容を送る。

## 方針（重要な前提）

ブラウザは `.ino` をコンパイルして書き込めない。そこで次の2段構えにする。

1. **スケッチは一度だけ** Arduino IDE で書き込む（`firmware/dna_console/dna_console.ino`）。LEDを描画し、USBシリアルで命令を受けるだけの汎用ファームにする。
2. **表示内容（パターン）をブラウザから送る**。Web Serial API でUSB経由に送信し、「保存」でマイコンのフラッシュに残す。保存後はPC・ブラウザなしでも同じ表示を再生する。

LEDの電源はUSB（VUSB）のみなので、LEDが光る状況では必ずUSBが刺さっている。USBシリアルで制御する方式は、この制約と相性が良い（BLEは電池のみではLEDが点かないため見送り）。

「スケッチをブラウザから送る」を、ブラウザ上でコンパイルして書き込む意味で想定していた場合は、ローカルサーバー＋`arduino-cli` を使う方式を後から追加できる（本計画の範囲外）。

## 基板とのLED対応（既存設計から確定済み）

| 項目 | 内容 |
| --- | --- |
| LED | 24個、1本のデータ線（D6）。ピクセル番号 = 部品番号 − 2（U2 = 0 … U25 = 23） |
| 塩基対 | 12対。対 k（0〜11）= ピクセル 2k（鎖A）と 2k+1（鎖B） |
| コドン | 4つ。コドン c = 対 3c〜3c+2（ピクセル 6c〜6c+5） |
| 既定配列 | 鎖A = ATG GCA TCG TAA、鎖B = その相補（シルクと同じ） |
| 既定色 | A 緑 / T 赤 / G 青 / C 琥珀（既存スケッチと同じ） |

## ファームウェア

- 起動: 既存スケッチと同じくUSB給電を待ち、D6を安全に初期化。24段を1個ずつ点灯する動作確認を行う。
- 保存済み設定があれば読み込む。なければ既定配列（ATG GCA TCG TAA）を表示。
- 通信: 115200 bps、1行1命令のASCII。`while(!Serial)` で待たず、受信は非ブロッキング。
- 表示: 最大16フレーム（1フレーム = 24個のRGB）。複数フレームは一定時間ごとに切り替え。
- エフェクト: 固定 / 成長（対ごとに増える） / 呼吸 / 波（らせんに沿って流れる） / コドン走査。
- 明るさ: ファーム側でも上限（既定128）にクランプ。既定値は既存の40。
- 保存: 設定をテキストでフラッシュ（InternalFileSystem）へ保存。ライブラリが無いボードコアでは保存だけ無効になる。

| 命令 | 内容 |
| --- | --- |
| `HELLO` | 識別と上限値を返す |
| `F <i> <RRGGBB×24>` | フレームiを設定 |
| `N <1-16>` / `T <ms>` | 使うフレーム数 / 切替間隔 |
| `B <0-255>` | 明るさ |
| `FX <0-4>` / `SP <1-10>` | エフェクト / 速さ |
| `DUMP` | 現在の設定を返す（読み戻し） |
| `SAVE` / `LOAD` | フラッシュへ保存 / 読込 |
| `TEST` / `CLR` | 1個ずつ点灯 / 全消灯 |

応答は `OK ...` または `ERR ...`。

## Webコンソール

ビルド不要の静的ページ（Chrome / Edge、Web Serial）。外部ライブラリなし。

1. **基板プレビュー**: 実際のLED座標・基板外形でライブ表示。LEDをクリックして塗れる。実機が無くても確認でき、エフェクトのシミュレーションも可能。
2. **コドン枠（4つ）**: 3文字入力・64コドン一覧・終止コドンから選択。アミノ酸と相補鎖を表示。
3. **文字→コドン**: 入力した文字ごとにコドンを表示し、4文字ずつフレームに展開（最大16フレーム = 64文字）。
   - 「アミノ酸1文字」: 標準遺伝暗号（M→ATG、`*`→TAA）。同義コドンはチップをクリックで切替。対応するアミノ酸が無い文字（B, J, O, U, X, Z など）は「対応なし」と表示し消灯。
   - 「6bit ASCII」: 空白〜`_` の64文字を2ビット×3の塩基3つ（0=A, 1=C, 2=G, 3=T）に割当てる全文字対応モード。大文字小文字は区別しない。
4. **ペイント**: 単位（LED / 塩基対 / コドン）と筆（A,T,G,C / 消灯 / 任意色）を選んでクリック。相補鎖の自動点灯を切替可能。
5. **フレーム・出力**: フレーム一覧、切替間隔、明るさ、エフェクト、速さ。自動送信、手動送信、保存、読み戻し、動作テスト、全消灯。
6. 作業内容はブラウザに自動保存。JSONで書き出し/読込。
