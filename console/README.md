# DNA LED コンソール

DNAアクセサリー（XIAO nRF52840 + XL-1010RGBC-WS2812B × 24）の表示を、ブラウザから制御する。計画は [PLAN.md](PLAN.md)。

- `firmware/dna_console/dna_console.ino`: 一度だけ書き込むスケッチ。USBシリアルの命令でLEDを表示する。
- `web/`: コンソール本体（ビルド不要の静的ページ）。
- `tools/make_board_data.py`: `design/` の実データから `web/board-data.js`（基板外形・LED座標）を生成。

## 状態

| 項目 | 状態 |
| --- | --- |
| Webコンソール | ブラウザで画面・文字→コドン変換・ペイント・フレーム・プロトコル文字列の生成と読み戻しを確認済み（機器の代わりに模擬応答で確認） |
| スケッチ | **未コンパイル・未書き込み**。この環境に `arduino-cli`・Seeed nRF52ボードコア・Adafruit NeoPixelが無いため。下の「実機での確認」を実施すること |
| Web Serialでの実機接続 | 未確認 |

## 1. スケッチを書き込む（最初の一度だけ）

1. Arduino IDE に **Seeed nRF52 Boards**（`Seeed XIAO nRF52840`。`mbed-enabled` ではない方）を入れる。
2. ライブラリマネージャーで **Adafruit NeoPixel** を入れる。
3. `firmware/dna_console/dna_console.ino` を開き、ボード `Seeed XIAO nRF52840` を選んで書き込む。
4. 起動すると24個が順に1個ずつ点灯し（動作確認）、その後は既定配列 ATG GCA TCG TAA を「成長」エフェクトで表示する。

既存の `firmware/dna_led/dna_led.ino` と同じく、USBが刺さっていない間はD6をハイインピーダンスにする。
保存機能（InternalFileSystem）を使わない場合は、スケッチ先頭の `#define DNA_USE_FS 1` を `0` にする。

## 2. コンソールを開く

Chrome または Edge（Web Serial対応）で `web/index.html` を開く。`file://` で動かない場合は次を実行して `http://localhost:8000/` を開く。

```bash
python -m http.server 8000 --directory console/web
```

機器が無くてもプレビューは使える（その場合「接続」は無効）。

## 3. 使い方

1. **接続** → ポート一覧からXIAOを選ぶ。接続時に `HELLO` で上限値などを取得する。
2. 表示内容を作る（上から順に）。
   - **コドン枠**: 4か所のコドンを、3文字入力・一覧選択・消灯から指定。アミノ酸と相補鎖を表示する。
   - **文字 → コドン**: 文字を入力するとコドンを表示。「基板に表示」（またはEnter）で4文字ずつフレームに展開（最大16フレーム = 64文字）。
     - `アミノ酸1文字`: 標準遺伝暗号。M→ATG、`*`/`.`→TAA。同義コドンがある文字はチップをクリックして切替。B, J, O, U, X, Z・数字などは「対応なし」で消灯。
     - `6bit ASCII`: 空白〜`_` の64文字を、2ビット × 3（A=0, C=1, G=2, T=3）の塩基3つに割当てる。大文字小文字は同じ扱い。
   - **ペイント**: 筆（A/T/G/C・消灯・任意色）と単位（LED/塩基対/コドン）を選び、プレビューのLEDをクリック。
   - **フレーム**: 追加・複製・削除・並べ替え。フレームが2つ以上のときは切替間隔ごとに順に表示。
3. **自動送信**がオンなら編集が即座に機器へ送られる。オフのときは「送信」。
4. 気に入ったら **保存（フラッシュ）**。以降はPCなしでUSB給電だけで再生する。
5. **読み戻し**で機器に保存されている内容を取り込む。**動作テスト**は24個を1個ずつ点灯する。

プレビューの右側に、現在のフレームの各コドンとアミノ酸を表示する。「エフェクト・フレーム切替をプレビュー」で、機器と同じ式のエフェクトを画面上で確認できる。

LEDの対応: ピクセル番号 = 部品番号 − 2（U2 = 0 … U25 = 23）。塩基対k = ピクセル 2k（鎖A）と 2k+1（鎖B）。コドンc = 対 3c〜3c+2。基板の `design/base-pairs.csv` と一致する。

## 4. 命令（USBシリアル 115200 bps、1行1命令）

応答は `OK …` または `ERR …`。手動で試すときはシリアルモニタ（改行コード LF）から送れる。

| 命令 | 内容 |
| --- | --- |
| `HELLO` | `OK DNA-LED 1 leds=24 frames=16 maxbri=128 fs=1` |
| `F <0-15> <RRGGBB×24>` | フレーム設定（144桁の16進。ピクセル0から順） |
| `N <1-16>` | 使うフレーム数 |
| `T <100-60000>` | フレーム切替間隔（ms） |
| `B <0-255>` | 明るさ。ファーム側で `MAX_BRIGHTNESS`（128）に丸め、`OK <実値>` を返す |
| `FX <0-4>` | 0固定 / 1成長 / 2呼吸 / 3波 / 4コドン走査 |
| `SP <1-10>` | エフェクトの速さ |
| `DUMP` | 現在の設定を命令形式で返し、最後に `END` |
| `SAVE` / `LOAD` | フラッシュ（`/dna.cfg`）へ保存 / 読込。保存形式は `DUMP` と同じテキスト |
| `DEF` / `CLR` | 既定配列に戻す / 全消灯 |
| `TEST` | 24個を1個ずつ点灯 |

## 5. 実機での確認（未実施）

1. スケッチがコンパイルできる（特に `InternalFileSystem.h`。エラーなら `DNA_USE_FS` を0に）。
2. 起動時の動作確認で24個すべてが順に点灯する。
3. 接続後、コドン枠に `ATG` などを入れて、基板のシルク（対番号・鎖A/B）と点灯位置が一致する。
4. 明るさは既定の40から。電流と最遠LEDのVDDを測るまで、`MAX_BRIGHTNESS` を上げない（フル白で約0.37 A @ 5 V、USB給電のみ）。
5. 保存 → USBを抜き差し → PCなしで同じ表示が復元される。
6. 一覧ポートが出ない場合は、書き込んだスケッチがCDCシリアルを有効にしているか（Seeed nRF52コアは既定で有効）を確認。

## 既知の制約

- 電池のみではLEDに電源が入らないため、制御・表示はUSB給電時のみ。BLE制御は採用していない。
- スケッチ本体の書き込みはブラウザからは行えない（Arduino IDE等で行う）。
- Web SerialはChrome / Edge系のみ。
