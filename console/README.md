# DNA LED コンソール

DNAアクセサリー（XIAO nRF52840 + XL-1010RGBC-WS2812B × 24）の表示を、ブラウザから制御する。計画は [PLAN.md](PLAN.md)。

- `firmware/dna_console/dna_console.ino`: 一度だけ書き込むスケッチ。USBシリアルの命令でLEDを表示する。
- `index.html` と、`app.js`（画面・Web Serial）、`codons.js`（遺伝暗号表）、`aminoacids.js`（アミノ酸データとキャラクター）、`molecules.js`（塩基の構造）、`wheel.js`（コドン表の円）、`helix.js`（3D二重らせん）、`theme.css` `style.css`、`board-data.js`: コンソール本体（ビルド不要の静的ページ。`console/` 直下）。
- 見た目は accel-kitchen.com のライトテーマ（Stardust Notebook）に合わせている。`theme.css` はそのサイトのトークンのコピー。
- `tools/make_board_data.py`: `design/` の実データから `board-data.js`（基板外形・LED座標）を生成。

## 触りながら学べること

- アルファベットかコドンを選ぶと、アミノ酸の名前・性質（疎水性、極性、酸性、塩基性、特殊）・豆知識、水に入れたときの動きが出る。
- 3つの塩基それぞれと、相手の塩基の構造、水素結合（A–Tは2本、G–Cは3本）を表示する。
- 1文字変えたときに、アミノ酸が変わるか（同義・ミスセンス・ナンセンス）を9通りのうち3通りずつ見比べられる。3番目の塩基のゆらぎも確認できる。
- A〜Z のアルファベット表と、64コドンの円形表。どちらからでも枠のコドンを選べ、円形表では同じアミノ酸になる仲間が光る。
- 「翻訳してみる」で、4つの枠を順に読んでアミノ酸をつなげる。読んでいるコドンは基板と3Dモデルでも光る。
- 3Dの二重らせんは、基板の12塩基対と同じ配列・同じ色で光る。ドラッグで回転、ホイールで拡大、ダブルクリックでリセット。

3Dモデルは three.js（r160、cdnjs）を読み込むので、インターネット接続が必要。つながらない場合は3Dだけが出ず、ほかは動く。
塩基の構造は標準的な位置・結合で描いた模式図。二重らせんの原子位置は B型DNA（1回転10.5塩基対、間隔0.34 nm）に合わせた模式的なもので、実測構造ではない。

## 1. スケッチを書き込む（最初の一度だけ）

1. Arduino IDE に **Seeed nRF52 Boards**（`Seeed XIAO nRF52840`。`mbed-enabled` ではない方）を入れる。
2. ライブラリマネージャーで **Adafruit NeoPixel** を入れる。
3. `firmware/dna_console/dna_console.ino` を開き、ボード `Seeed XIAO nRF52840` を選んで書き込む。
4. 起動すると24個が順に1個ずつ点灯し（動作確認）、その後は既定配列 ATG GCA TCG TAA を「成長」エフェクトで表示する。

LEDの電源は、USBが刺さっていればUSBの5 V、無ければ電池を基板上の昇圧回路（MT3608B）で5 Vにしたもの。切り替えは回路が自動で行うので、スケッチは電源の状態を見ない。電池は基板上の電源スイッチ（SW1、改訂7）で入り切りする。OFFにすると、USBが無ければ何も動かない（待機電流もほぼ0）。USBがあれば動くが、電池は3.5 V程度までしか充電されない（満充電するにはON）。
保存機能（InternalFileSystem）を使わない場合は、スケッチ先頭の `#define DNA_USE_FS 1` を `0` にする。

## 2. コンソールを開く

Chrome または Edge（Web Serial対応）で `console/index.html` を開く。`file://` で動かない場合は次を実行して `http://localhost:8000/` を開く。

```bash
python -m http.server 8000 --directory console
```

機器が無くてもプレビューは使える（その場合「接続」は無効）。

## 3. 使い方

1. **接続** → ポート一覧からXIAOを選ぶ。接続時に `HELLO` で上限値などを取得する。
2. 表示内容を作る（上から順に）。
   - **基板の右の1〜4（コドン枠）**: 4か所のコドン。押すと選ばれ、塩基タイルを押すと変える位置も選べる。
   - **アルファベットから選ぶ**: A〜Z と ＊（終止）の表。文字を選ぶと、そのアミノ酸のコドンが選んでいる枠に入る（M→ATG、＊→TAA）。B・J・O・U・X・Z は対応するコドンがないので、選ぶと理由が出る。
   - **コドンから選ぶ**: 64コドンの円形表。クリックで枠のコドンが変わる。マウスを重ねるとそのコドンの紹介が出る。「翻訳してみる」と「4つの塩基」もここにある。
   - どちらのタブでも、下に「選んだコドン」の紹介（アミノ酸の性質、塩基と水素結合、1文字変えたときの変化、塩基3文字の直接入力）が出る。
   - **ペイント**: 筆（A/T/G/C・消灯・任意色）と単位（LED/塩基対/コドン）を選び、プレビューのLEDをクリック。
   - **フレーム**: 追加・複製・削除・並べ替え。フレームが2つ以上のときは切替間隔ごとに順に表示。
3. **自動送信**がオンなら編集が即座に機器へ送られる。オフのときは「送信」。
4. 気に入ったら **保存（フラッシュ）**。以降はPCなしで（USB給電でも、電池でも）再生する。
5. **読み戻し**で機器に保存されている内容を取り込む。**動作テスト**は24個を1個ずつ点灯する。

プレビューの右側に、現在のフレームの各コドンとアミノ酸を表示する。「エフェクト・フレーム切替をプレビュー」で、機器と同じ式のエフェクトを画面上で確認できる。

LEDの対応: ピクセル番号 = 部品番号 − 2（U2 = 0 … U25 = 23）。塩基対k = ピクセル 2k（鎖A）と 2k+1（鎖B）。コドンc = 対 3c〜3c+2。基板の `design/base-pairs.csv` と一致する。

## 4. 命令（USBシリアル 115200 bps、1行1命令）

応答は `OK …` または `ERR …`。手動で試すときはシリアルモニタ（改行コード LF）から送れる。

| 命令 | 内容 |
| --- | --- |
| `HELLO` | `OK DNA-LED 1 leds=24 frames=16 maxbri=128 fs=1` |
| `F <0-15> <RRGGBB×24>` | フレーム設定（144桁の16進。ピクセル0から順） |
| `N <1-16>` | 使うフレーム数 |
| `T <100-60000>` | フレーム切替間隔（ms） |
| `B <0-255>` | 明るさ。ファーム側で `MAX_BRIGHTNESS`（128）に丸め、`OK <実値>` を返す |
| `FX <0-4>` | 0固定 / 1成長 / 2呼吸 / 3波 / 4コドン走査 |
| `SP <1-10>` | エフェクトの速さ |
| `DUMP` | 現在の設定を命令形式で返し、最後に `END` |
| `SAVE` / `LOAD` | フラッシュ（`/dna.cfg`）へ保存 / 読込。保存形式は `DUMP` と同じテキスト |
| `DEF` / `CLR` | 既定配列に戻す / 全消灯 |
| `TEST` | 24個を1個ずつ点灯 |

## 5. 実機での確認（未実施）

1. スケッチがコンパイルできる（特に `InternalFileSystem.h`。エラーなら `DNA_USE_FS` を0に）。
2. 起動時の動作確認で24個すべてが順に点灯する。
3. 接続後、コドン枠に `ATG` などを入れて、基板のシルク（対番号・鎖A/B）と点灯位置が一致する。
4. 明るさは既定の40から。電流と最遠LEDのVDDを測るまで、`MAX_BRIGHTNESS` を上げない（フル白で約0.37 A @ 5 V。電池では3.0 Vの電池から約0.7 A。小さな電池では `MAX_BRIGHTNESS` を低く保つ）。
5. 保存 → USBを抜き差し → PCなしで同じ表示が復元される。
6. 一覧ポートが出ない場合は、書き込んだスケッチがCDCシリアルを有効にしているか（Seeed nRF52コアは既定で有効）を確認。

## 既知の制約

- コンソールからの制御（USBシリアル）はUSB接続時のみ。保存した表示は、電池だけでも再生される。BLE制御は採用していない。
- スケッチ本体の書き込みはブラウザからは行えない（Arduino IDE等で行う）。
- Web SerialはChrome / Edge系のみ。
